## 1. Project Overview

**Esports Management System** is a web-based application designed to organize and manage esports-related activities through a centralized platform.

The system aims to provide an organized environment for managing esports tournaments, teams, players, registrations, and competition-related information.

It is designed to simplify tournament management and improve the overall organization of esports activities.

## 2. Project Introduction

Esports has become an important part of the modern gaming industry. Managing tournaments, teams, participants, and competition schedules requires an organized system.

The Esports Management System aims to provide a digital solution for these management activities.

The application is designed to make esports-related information easier to organize, manage, and access.

## 3. Project Objectives

The main objectives are:

- Develop a web-based esports management platform.
- Organize esports-related information.
- Manage tournament information.
- Maintain team and player records.
- Support tournament registration workflows.
- Improve competition management.
- Provide an organized management interface.
- Simplify esports event administration.

## 14. Installation Guide

### Step 1: Install XAMPP

Download and install XAMPP.

### Step 2: Copy Project

Place the project folder inside the XAMPP `htdocs` directory.

Example:

```text
htdocs/Esports-Management-System/
```

### Step 3: Start Services

Start the following services:

- Apache
- MySQL

### Step 4: Database Setup

Open phpMyAdmin.

Create the database using the name specified in the project configuration and import the supplied SQL file, if available.

### Step 5: Configure Database

Check the database configuration file and update the local connection details.

### Step 6: Run Application

Open the project in your browser:

```text
http://localhost/Esports-Management-System/
```

The URL may vary depending on the actual project folder name.
